## Собственный проект

Тема проекта: Игровая библиотека

Главный класс: Game

Почему этот объект нужен программе:
Этот объект будет отвечать за обозначения необходимыми характеристиками игры

Какие данные хранит объект:

- Название
- Жанр
- Год издания
- Рейтинг

Какие значения задаются через конструктор:
Название, Жанр, Год издания

Какие значения можно задавать автоматически:
Рейтинг

## 2 Лабораторная

Ко своему проекту я добавил метод Rate (который отвечает за получение или убавления рейтинга игры), а также метод GetInfo, который пишет информацию об объекте.

В Rate я сделал проверку рейтинга, если при сложении оно выходит за рамки 100 или 0, то этот рейтинг не проходит. А, допустим, 10 проходит (при базовом значении 1).
